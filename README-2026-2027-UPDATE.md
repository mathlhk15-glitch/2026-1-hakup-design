# 경일 학업설계 플랫폼 통합 업데이트

- 기존 GitHub Pages 주소 유지, 저장소 안 파일만 교체합니다.
- 2026 및 2027학년도 입학생을 대상으로 입학연도 선택을 연동했습니다.
- 대학 권장과목은 **2028학년도 대입 자료**입니다. 2026 입학생 2029 대입, 2027 입학생 2030 대입에 그대로 적용되는 확정 기준이 아닙니다.
- 공통 과목 데이터: `common/curriculum-gyeongil.js`. 2026은 사용자가 제공한 2026 편제표(엑셀), 2027은 변경 후 편제표(PDF)를 기준으로 재사용합니다.
- `choice/`의 경일고 과목 선택군을 공통 데이터 기반으로 변경했습니다. 경일여고는 기존 2026 편제를 유지하고 2027은 편제표가 없어 차단합니다.
- `univ-subjects/`는 새 검색기이며 대학 757건의 자동정제 데이터가 포함되어 있습니다. 미검증 항목은 원문 확인 필요입니다.
- 남고 편제표의 선택군 학기·신청 제한은 최종 수강신청 전에 교육과정부 확인이 필요합니다.
- 브라우저의 로컬 저장값은 이전 사이트의 선택 상태와 다를 수 있으며 수강신청 데이터로 간주해서는 안 됩니다.
- 학생용 공개 시 `teacher/`는 제거해야 합니다.
