# 경일 학업설계 플랫폼 v3.2

창원경일고·창원경일여고 1학년의 선택과목 설계를 돕는 통합 웹 플랫폼.
학생은 하나의 사이트처럼 사용하고, 관리자는 앱별로 독립 관리한다.

시스템 구조·확장 방법·변경 원칙은 `ARCHITECTURE.md` 참조.

## 실행 방법

- 로컬: `index.html`을 브라우저로 연다. **폴더 구조를 그대로 유지**해야 한다(이미지·공통 스크립트가 상대경로).
- 웹 게시: 폴더 전체를 GitHub Pages 등 정적 호스팅에 업로드. **`teacher/` 폴더는 업로드에서 제외**하면 그대로 학생용 사이트가 된다.
- 권장 배포: 웹 주소 + QR코드(학생), ZIP 백업본(교사).

```

├─ common/
│  ├─ navigation.js            공통 내비게이션 + 학교 상태 API(GyeongilPortal)
│  ├─ subject-images.js        과목명→안내서 이미지 공통 맵(choice ? 아이콘용)
│  └─ portal.css               포털 스타일(밝은 테마 + 카드 UI)
├─ major/                      1단계 · 전공 탐색 사전 (19개 대학, index.html + data.js)
├─ subjects/                   2단계 · 학과·과목 설명 (index.html + assets/ 이미지 334개)
│  └─ assets/                  img(학과), subj(과목 설명), pp(책자 페이지), pyeon.jpg
├─ choice/                     3단계 · 선택과목 설계 도우미 (두 학교 실제 편제표)
```

## 이번 업데이트(v3) 핵심

1. **학교 선택 자동 연동**: 포털에서 한 번 선택하면 `localStorage('gyeongil.school')`을 통해 전 앱이 공유. choice는 해당 학교 편제표를 자동 로드하며, choice에서 바꾸면 포털에도 반영(양방향). 학교별 구분색: 경일고 파랑 / 경일여고 로즈.
2. **subjects 성능 개선**: 본문 34.5MB → **2.1MB(94% 감소)**. base64 내장 이미지 334개(학과 121 + 과목 123 + 책자 89 + 편제표 1)를 `assets/` 외부 파일로 분리하고 `loading="lazy"` 적용. 첫 로딩이 이미지 전체가 아닌 본문만 받게 됨.
3. **포털 카드 UI**: 밝은 테마 유지 + 그라디언트 단계 번호, 호버 애니메이션, 단계별 대상 안내, CTA 버튼.
4. **원자료 크레딧 복원**: 전남여고 김동석 선생님 제작자 표기를 헤더·포털 푸터에 유지(연구윤리).
5. **예시 편제표 안내 강화**: ⑤예시 편제표·⑥나의 설계(예시) 탭에 경고 배너 + 3단계(choice) 이동 링크.
6. **roadmap → choice 연결**: 12단계 완주 화면에 "우리 학교 시간표 설계" CTA 추가.
7. **A4 인쇄 개선**: `@page A4` 지정, 상담 요약이 열려 있으면 요약만 인쇄되는 모드 추가.
8. **접근성**: aria-current/aria-pressed/aria-live/role, focus-visible 아웃라인, 44px 탭 타깃(모바일).

## 확장 방법 (카드 추가)

`index.html`의 `<ol class="steps">` 안 `<li>` 하나를 복사해 내용만 바꾸면 새 기능 카드가 추가된다(주석 가이드 참조). 예정: AI 진로, 경제·투자, 심리검사, 대입자료, 생활기록부, 학습전략, AI 챗봇. 새 앱은 하위 폴더(`newapp/index.html`) + `<html data-portal-page="키">` + navigation.js 포함이면 나머지가 자동 적용된다.

## 알려진 제한사항

- **localStorage 한계**: 기기·브라우저가 바뀌면 학교 선택이 이어지지 않는다. 최종 결과는 인쇄/복사로 보관해야 한다(포털 안내문 포함). 개인정보는 저장하지 않는다.
- **앱 간 관심 학과 연동은 미구현(Phase 2)**: 학과명 자동 매칭률 57.9%(후보 포함 82.8%). 표준 학과 ID·별칭표 검토 후 진행해야 한다. `학과명-일치율-점검.md` 참조.
- **major 바텀시트 전환 보류**: 현재 상세 화면이 아코디언(카드 내 확장) 구조라 바텀시트 전환은 검색·필터 상태 로직 재작성이 필요하다. v3에서는 모바일 탭 타깃·전개 애니메이션만 보강.
- `file://`로 열 때 일부 브라우저에서 localStorage가 탭 간 공유되지 않을 수 있다. 웹 게시 시 정상 동작.
